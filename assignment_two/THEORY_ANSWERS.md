
## الفرق بين Adjacency List و Adjacency Matrix

مصفوفة الجوار (Adjacency Matrix)
- **تمثيل:** مصفوفة V×V (رقم 1 يعني وجود حافة، 0 يعني لا يوجد)
- **المساحة:** O(V²) ← كبير
- **فحص حافة:** O(1) ← سريع
- **إضافة عقدة:** O(V²) ← بطيء
رسم بياني كثيف (كل عقدة متصلة بمعظم العقد)

قائمة الجوار (Adjacency List)
- **تمثيل:** كل عقدة لها قائمة بالعقد المتصلة بها
- **المساحة:** O(V+E) ← صغير
- **فحص حافة:** O(درجة العقدة) ← أبطأ
- **إضافة عقدة:** O(1) ← سريع
- **مثال:** رسم بياني متناثر (مثل شبكات التواصل)

مقارنة سريعة:
| المعيار | المصفوفة | القائمة |
|---------|----------|---------|
| **الذاكرة** | O(V²) | O(V+E) |
| **فحص حافة** | O(1) | O(degree) |
| **إضافة عقدة** | O(V²) | O(1) |
| **كفاءة في رسم كثيف** | ✓ ممتاز | ✗ ضعيف |
| **كفاءة في رسم متناثر** | ✗ ضعيف | ✓ ممتاز |

متى نستخدم؟
- **استخدم المصفوفة:** رسم بياني صغير/كثيف، تحتاج فحص حواف سريع
- **استخدم القائمة:** رسم بياني كبير/متناثر، الذاكرة محدودة
